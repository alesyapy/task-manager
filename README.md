# Task Manager

Упрощённый аналог Trello для управления задачами.

## Возможности

- вход по username
- создание досок
- создание колонок
- создание карточек
- редактирование и удаление
- загрузка изображений
- drag-and-drop карточек

## Стек

Frontend:
- React + Vite
- Redux Toolkit

Backend:
- Node.js + Express
- PostgreSQL
- Prisma

## Запуск проекта

### Backend

cd backend  
npm install  
npm run dev  

### Frontend

cd frontend  
npm install  
npm run dev
